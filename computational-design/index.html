01 / Scope

Computational design & architectural automation

I use computational methods to study architectural geometry, develop repeatable design workflows and connect different design tools. My focus is not only on generating forms, but also on making project information easier to manage, transfer and reuse.

Workflow automation

Reducing repeated manual steps in Rhino and Grasshopper projects, including organizing related model and definition files.

Parametric design

Developing and testing geometry through mathematical rules, parameters and visual programming in Grasshopper.

BIM interoperability

Exploring how geometry generated with Grasshopper can become editable architectural elements within Autodesk Revit.

Design research

Applying systems thinking, simulation and analytical workflows to architectural and human–machine research.

02 / Published software

RGLink — Rhino & Grasshopper workflow tool

I developed RGLink, a published plugin for Rhino that links one .3dm project with multiple Grasshopper .gh or .ghx definitions. The plugin provides a way to access the associated definitions from the Rhino project rather than repeatedly locating and opening separate files.

The RGLINK command is intended for projects that depend on several Grasshopper definitions. The initial public release supports Rhino 7 and 8, as described in the McNeel community announcement dated 28 August 2026.
